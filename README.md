# simpson

适用于 Scoop 包管理器的应用程序清单仓库。

## 如何使用

确保你已经安装了 [Scoop](https://scoop.sh/)，然后在 PowerShell 中运行：

```powershell
scoop bucket add simpson https://github.com/nosomebodyone/simpson
```

### 安装软件

```powershell
scoop install simpson/<manifest>
```

### 移除仓库

```powershell
scoop bucket rm simpson
```
